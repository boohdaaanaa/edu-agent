# EduAgent — Освітній AI-агент для кафедри

> Інтелектуальна система для пошуку та аналізу навчальних матеріалів з використанням штучного інтелекту та веб-пошуку в реальному часі.

---

## Про проект

**EduAgent** — це проект, що реалізує AI-агента для автоматизованого збору та аналізу освітніх матеріалів. Користувач задає тему (наприклад, _«навчальна програма з комп'ютерних наук»_) — агент здійснює пошук в інтернеті, аналізує знайдені джерела та формує структурований звіт.

### Що вміє агент

- Шукати в інтернеті навчальні програми, методичні вказівки, силабуси, підручники та наукові статті
- Аналізувати знайдений контент за допомогою великої мовної моделі (LLM)
- Формувати структурований звіт українською мовою
- Відображати джерела з посиланнями на оригінальні сторінки
- Зберігати результат у форматі Markdown

## Технологічний стек

### Backend
| Технологія | Призначення |
|---|---|
| **Python 3.11+** | Основна мова бекенду |
| **FastAPI** | REST API сервер з підтримкою async/await |
| **Groq API** | Безкоштовний доступ до LLM (LLaMA 3.3 70B) |
| **Tavily API** | Веб-пошук у реальному часі |


### Frontend
| Технологія | Призначення |
|---|---|
| **React 18** | UI-бібліотека |
| **Vite** | Збірник та dev-сервер |
| **react-markdown** | Рендеринг Markdown у відповіді агента |

## Як запустити проект

### 1. Отримайте безкоштовні API ключі

#### Groq API (LLM — безкоштовно)
1. Зайдіть на [console.groq.com](https://console.groq.com)
2. Зареєструйтесь або увійдіть через Google
3. Перейдіть в розділ **API Keys** → **Create API Key**
4. Скопіюйте ключ (виглядає як `gsk_...`)

#### Tavily API (веб-пошук — безкоштовно до 1000 запитів/місяць)
1. Зайдіть на [tavily.com](https://tavily.com)
2. Натисніть **Get Started** → зареєструйтесь
3. На дашборді скопіюйте ваш **API Key** (виглядає як `tvly-...`)

---

### 2. Налаштуйте бекенд

```bash
# Перейдіть у папку бекенду
cd backend

# Створіть файл .env з вашими ключами
cp .env.example .env
```

Відкрийте `.env` і вставте ваші ключі:
```env
GROQ_API_KEY=gsk_ваш_ключ_тут
TAVILY_API_KEY=tvly-ваш_ключ_тут
```

```bash
# Створіть та активуйте віртуальне середовище
python -m venv venv

# Windows:
venv\Scripts\activate

# macOS / Linux:
source venv/bin/activate

# Встановіть залежності
pip install -r requirements.txt

# Запустіть сервер
python main.py
```

Бекенд запущено на `http://localhost:8000`

---

### 3. Налаштуйте фронтенд

```bash
# Відкрийте нову вкладку терміналу
cd frontend

# Встановіть залежності
npm install

# Запустіть dev-сервер
npm run dev
```

Фронтенд запущено на `http://localhost:3000`

---

### 4. Відкрийте застосунок

Перейдіть у браузері на **[http://localhost:3000](http://localhost:3000)**

## Як користуватись

1. **Оберіть тип матеріалу** — натисніть на одну з категорій:
   - 🔍 Вільний пошук — для будь-яких запитів (ціни, вступ, загальна інформація)
   - 📚 Навчальна програма
   - 📋 Методичні вказівки
   - 🗓 Навчальний план
   - 📖 Підручники та посібники
   - та інші...

2. **Введіть тему пошуку** — наприклад:
   - `НУЛП комп'ютерні науки`
   - `Штучний інтелект силабус`
   - `Вартість навчання НУЛП 2024`

3. **Натисніть «Запустити пошук»** — агент:
   - 🌐 Шукає в інтернеті (Tavily)
   - 🧠 Аналізує знайдене (Groq LLaMA)
   - 📊 Виводить результат у реальному часі

4. **Збережіть результат** — кнопка `.md` завантажує звіт у форматі Markdown

## Архітектура роботи агента

```
Користувач вводить тему
        │
        ▼
  [Frontend React]
  SearchForm → useAgent hook
        │
        ▼ POST /api/agent/stream
  [Backend FastAPI]
        │
        ├─► build_search_query()
        │       └─ формує точний запит залежно від категорії
        │
        ├─► Tavily API (веб-пошук)
        │       └─ повертає 7-8 релевантних джерел
        │
        ├─► deduplicate_sources()
        │       └─ прибирає дублікати по URL
        │
        └─► Groq API (LLaMA 3.3 70B)
                └─ аналізує контент → стримінг токенів
                        │
                        ▼ Server-Sent Events
              [Frontend React]
              StatusPanel + ResultPanel
```

## Опис ключових модулів

### `backend/main.py`

| Функція / Ендпоінт | Опис |
|---|---|
| `build_search_query()` | Будує пошуковий запит залежно від теми та категорії. Зберігає власні назви (НУЛП, Харків тощо) |
| `deduplicate_sources()` | Видаляє дублікати джерел за URL |
| `tavily_search()` | Async запит до Tavily API, повертає список релевантних веб-сторінок |
| `POST /api/agent/stream` | Основний ендпоінт: пошук → аналіз → стримінг SSE-відповіді |
| `GET /health` | Перевірка стану сервера та наявності API ключів |

### `frontend/src/hooks/useAgent.js`

Кастомний React-хук що керує всім циклом роботи агента: відправка запиту, читання SSE-потоку, оновлення стану (searching → analyzing → done).

### `frontend/src/components/`

| Компонент | Опис |
|---|---|
| `SearchForm.jsx` | Форма з вибором категорії та полем вводу теми |
| `StatusPanel.jsx` | Покроковий індикатор прогресу агента |
| `ResultPanel.jsx` | Відображення Markdown-результату з джерелами |

## Відомі обмеження

- Tavily безкоштовний план: **1 000 запитів/місяць**
- Groq безкоштовний план: **30 запитів/хвилину**, ліміт токенів
- Якість результатів залежить від наявності інформації у відкритому вебі
